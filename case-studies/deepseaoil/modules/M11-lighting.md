# M11 光照

## 解决什么问题

同屏大量 URP 2D 点光成本高，光斑又是圆形，不贴合瓦片边界和墙体遮挡。

## 结构

把火、电、泉眼等光源写入网格；在 CPU 上做受墙体和透过率影响的空间扩散；把每格结果烘成低分辨率光照纹理；Shader 与 Sprite/地形最终合成。

## 模式与思想

- 主要是**算法 + 渲染管线适配**，不是 GoF 设计模式。
- 空间扩散可借鉴距离场、波前和最大通道合成。

## 可复用精华

“按需更新 + 低分辨率中间纹理 + 最终合成”是跨项目图形工程思路，但首版没有可运行 Unity 图形 Kit。

## 边界

性能收益取决于分辨率、刷新频率和重建范围，不能笼统宣称“按面积付费一定更快”。
