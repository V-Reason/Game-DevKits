# 模式术语表

## 设计原则

| 缩写 | 名称 | 一句话判据 |
| --- | --- | --- |
| OCP | 开闭原则 | 新变化应对扩展开放，对已有稳定代码修改关闭 |
| SRP | 单一职责原则 | 一个模块应只有一个主要变化原因 |
| LSP | 里氏替换原则 | 子类型应能履行父类型承诺 |
| ISP | 接口隔离原则 | 客户端不应依赖自己不用的能力 |
| DIP | 依赖倒置原则 | 高层策略与低层细节都依赖抽象 |
| LoD | 迪米特法则 | 只与直接协作者说话 |
| CRP | 合成复用原则 | 优先组合，而不是为复用继承实现 |

## GoF 模式口径

| 分类 | 模式 | 本项目中的真实关系 |
| --- | --- | --- |
| 创建型 | 简单工厂 | `EffectDriverFactory` 类案例；非 GoF 23 |
| 创建型 | 工厂方法 | 未作为主范式 |
| 创建型 | 抽象工厂 | 未作为主范式 |
| 创建型 | 建造者 | 组合根有分步装配思想，不强行贴 Builder |
| 创建型 | 原型 | 配置行有原型数据思想，运行时通常新建实例 |
| 创建型 | 单例 | GameRoot 是唯一真单例 |
| 结构型 | 适配器 | 刚体、Tilemap、Unity 时间接入逻辑端口 |
| 结构型 | 桥接 | 非核心案例 |
| 结构型 | 组合 | Unity 层级天然体现，未作为独立 Kit |
| 结构型 | 装饰器 | 非核心案例 |
| 结构型 | 外观 | Config、Asset、Effect、UI 模块收敛子系统 |
| 结构型 | 代理 | 异步资源句柄有受控访问思想 |
| 行为型 | 责任链 | 非核心案例 |
| 行为型 | 命令 | 事件不是统一 Command |
| 行为型 | 中介者 | 组合根不是正式 Mediator |
| 行为型 | 观察者 | EventBus 与 UI/音频/表现订阅 |
| 行为型 | 状态 | 玩家、敌人、地块、波次和关卡 |
| 行为型 | 策略 | 敌人 Brain、表现 Driver、流场成本策略 |
| 行为型 | 模板方法 | 状态组固定推进骨架有近似思想 |

## 易混对照

| A | B | 区别 |
| --- | --- | --- |
| State | Strategy | State 关注内部迁移和生命周期；Strategy 关注外部选择算法 |
| Observer | Mediator | Observer 做事实广播；Mediator 协调多个参与者交互 |
| Simple Factory | Factory Method | 简单工厂集中分支；工厂方法把创建延迟到子类 |
| Adapter | Facade | Adapter 转换接口；Facade 简化子系统入口 |
| Object Pool | Flyweight | Pool 复用有状态实例；Flyweight 共享不变数据 |
| Memento | Command | Memento 恢复完整快照；Command 封装可排队/撤销请求 |
| MVC | MVVM | MVC/MVVM 是架构模式；事件订阅本身不是 MVC |

## 额外游戏工程概念

Composition Root、手动 DI、对象池、双缓冲、脏标记、更新调度、数据驱动、流场、距离场、时间轮不是 GoF 23 的同层概念，文章中必须单独标注层级。
